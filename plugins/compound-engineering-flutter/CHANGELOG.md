# Changelog

## [1.0.0] - 2026-03-11

### 新增

- 8 个专业 Flutter Agent
  - `flutter-code-reviewer` - Flutter/Dart 代码审查
  - `dart-style-reviewer` - Effective Dart 风格审查
  - `widget-architect` - Widget 架构设计
  - `state-management-advisor` - 状态管理架构（Bloc/Riverpod/Provider）
  - `flutter-performance-optimizer` - 性能优化
  - `platform-channel-expert` - 平台通道交互
  - `flutter-test-strategist` - 测试策略设计
  - `flutter-security-reviewer` - 安全审查
  - `flutter-navigation-designer` - 路由架构设计

- 6 个工作流命令
  - `/flutter:review` - 多维度代码审查
  - `/flutter:plan` - 功能实现计划
  - `/flutter:work` - 按计划执行开发
  - `/flutter-lfg` - 全自动工程工作流
  - `/flutter-new-feature` - 功能模块脚手架生成
  - `/flutter-analyze` - 项目健康检查

- 5 个领域知识 Skill
  - `flutter-clean-architecture` - Clean Architecture 实践
  - `dart-style` - Dart 编码规范
  - `widget-patterns` - Widget 设计模式
  - `flutter-testing` - 测试最佳实践
  - `flutter-app-setup` - 项目初始化配置

- 1 个 MCP Server
  - `context7` - 框架文档实时查询
